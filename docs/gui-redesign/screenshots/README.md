# Screenshot index

Two sets of PNG captures of the EDMRN window and its dialogs. Each table row describes one image. Sizes are pixel dimensions.

- **Set 1, fresh captures** (`01-` to `13-`, this folder): captured from the current app state with empty data (no CSV loaded, no route calculated, no system fetched). Dialogs 12 and 13 are small crops of the Settings tab, not the confirm and error dialogs their file names suggest.
- **Set 2, older captures** (`SS000.png` to `SS017.png`, in `screenshots/` at the repository root): captured from the original project with real data loaded. They predate some additions: the header has no "Fuel" field, there is no "Custom Route" tab, the range label has no "Auto" switch, there is no "Saved routes" button, and the Settings tab has no Crew card.
