## The project

EDMRN is a fork of *ED Multi Route Navigation* (NinurtaKalhu/Elite-Dangerous-Multi-Route-Optimizer,
AGPL-3.0), a Python/customtkinter desktop route planner for Elite Dangerous. The fork adds journal
location detection, saved routes, and crew features for a small group of friends: who is where in
what ship, explored systems, finds, notes and the leader's route, exchanged as a signed event log.
